# Add to this list

This list uses these terms:

- An **item** is one line of the list: a link and its description.
- A **workspace** is a repository of QREtools questions and instruments.
- A **dataset** is a DDI document that holds the answers to an instrument and their
  provenance.

## The conditions for an item

An item must agree with all of these conditions:

- The item is public.
- The item works with QREtools, or QREtools uses it.
- The list does not have the item already.

## Add an item

1. Fork this repository.
2. Find the correct section in `README.md`.
3. Add the item at the end of that section.
4. Write the item in this format: `- [Name](URL) - Description.`
5. Write the description to the rules below.
6. Open a pull request with only this item.
7. Make sure that the `lint` check passes.

## The rules for a description

The descriptions use ASD-STE100 Simplified Technical English.

- Write one or two sentences.
- Write 25 words or fewer in each sentence.
- Use the active voice.
- Do not use the -ing form of a verb as a noun or a verb.
- Write the full form: "do not", not "don't".
- Use the terms above, and use each term for one thing only.

## Change or remove an item

1. Open a pull request that changes or removes the item.
2. In the pull request, give the reason for the change.
